Customer Shopping Behavior Analysis

 Project Overview

Customer Shopping Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns, spending behavior, product preferences, and subscription trends. The project uses Python, MySQL, and Microsoft Power BI to transform raw customer shopping data into meaningful insights through data analysis and visualization.

The main goal is to explore customer behavior and present useful business insights through an interactive dashboard.

Objectives

- Clean and prepare the customer shopping dataset.
- Analyse customer purchasing patterns and spending behavior.
- Identify product category and customer preference trends.
- Examine discount usage, subscription status, and review ratings.
- Use SQL queries to answer business-related questions.
- Create an interactive Power BI dashboard to present key metrics and insights.

Tools and Technologies

- Python: Data cleaning, preparation, and analysis.
- Pandas and NumPy: Data manipulation and numerical calculations.
- Matplotlib and Seaborn: Data visualization, where used.
- Jupyter Notebook in VS Code: Python development environment.
- MySQL Workbench: Database creation, data import, and SQL analysis.
- SQL: Data filtering, aggregation, grouping, subqueries, and window functions.
- Microsoft Power BI: Interactive dashboard development.
- DAX: Creation of calculated measures and key performance indicators.
- CSV: Dataset storage and transfer between tools.

 Project Workflow

 Step 1: Dataset Collection

Collected a customer shopping behavior dataset in CSV format containing information about customer demographics, purchased products, purchase amounts, review ratings, discounts, shipping methods, previous purchases, and subscription status.

 Step 2: Data Inspection Using Python

Imported the dataset into a Jupyter Notebook in VS Code and examined its structure, columns, data types, and records.

 Step 3: Data Cleaning and Preparation

Used Python to inspect and prepare the dataset by checking missing values, data types, and inconsistencies. The prepared dataset was exported to a CSV file for further analysis.

 Step 4: Database Creation Using MySQL

Created a database in MySQL Workbench and imported the prepared CSV dataset into a table. Verified the imported records and table structure using SQL queries.

 Step 5: SQL Data Analysis

Executed SQL queries to investigate customer shopping behavior and answer business questions related to:

- Revenue generated by customer gender.
- Discount usage and customer spending.
- Products with higher average review ratings.
- Average spending across shipping types.
- Purchasing patterns of subscribed and non-subscribed customers.
- Repeat purchasing behaviour.
- Popular products within product categories.
- Customer segmentation based on previous purchases.
- Revenue distribution across customer age groups.

 Step 6: Data Import into Power BI

Imported the prepared CSV dataset directly into Microsoft Power BI Desktop and checked the available fields for dashboard development.

 Step 7: DAX Measures

Created DAX measures to calculate key metrics, including:

- Total Customers
- Average Purchase Amount
- Average Review Rating
- Other purchase and revenue metrics used in the dashboard

 Step 8: Dashboard Development

Developed an interactive dashboard titled **Customer Behavior Dashboard** using Power BI.

The dashboard includes KPI cards, a subscription status donut chart, revenue by category, sales by category, and slicers for exploring customer data by gender, product category, and shipping type.

 Step 9: Dashboard Validation

Reviewed the dashboard metrics and charts and tested the slicers to ensure that the report responded correctly to user selections.
